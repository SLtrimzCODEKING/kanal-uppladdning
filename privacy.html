Privacy Policy

Last updated: November 22, 2026

This policy describes how the Animated Shorts Studio upload tool (the "tool") handles data. The tool is a private program that runs only on the owner's own computer. It is used by the owner to manage the owner's own YouTube channels. It is not a public service and has no other users.

What the tool accesses

When the owner signs in with Google, the tool asks for these permissions:

  • https://www.googleapis.com/auth/youtube.upload: to upload the owner's own videos and thumbnails to the owner's own channels.
  • https://www.googleapis.com/auth/youtube.readonly: to confirm which channel is signed in and to read the status of uploaded videos.
  • https://www.googleapis.com/auth/yt-analytics.readonly: to read statistics (such as views and watch time) for the owner's own videos.

The tool does not access any other person's channel, videos, comments or account data.

Where data is stored

All data stays on the owner's own computer. This includes sign-in tokens, upload logs and statistics. The tool has no server or database, and it does not store this data in the cloud.

Sharing

We do not sell, share, transfer or disclose any data from Google APIs to anyone. We do not use it for advertising and we do not use it to train AI models. Data is only exchanged directly between the owner's computer and Google's own YouTube services.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time on the Google account permissions page: myaccount.google.com/permissions. Revoking access stops the tool from reaching YouTube. Deleting the tool's folder from the computer removes all locally stored data.
